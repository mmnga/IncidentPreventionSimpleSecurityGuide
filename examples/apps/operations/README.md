# 運用・実環境の記録モデル

このフォルダは全て架空の記入モデルです。実際のMFA・端末・SaaS・バックアップ・復元・通知等の成功証拠ではありません。個別の実行時刻・実アカウント・署名・証拠hashを捏造しません。

`external-controls.json` はstatic対象外48項目をそれぞれ未実施として残します。`full-criteria.json` はfull個別127条件の証拠が必要になる場所を示す未記入モデルです。監査証拠schemaとは別の形式で、そのまま `--evidence` へ渡せません。

実施する場合は別途許可された環境と対象・担当・記録・実測値・独立承認が必要です。このrepoの例を読むだけで、失効・隔離・復元・侵入試験・大量暗号化などを実行しません。
